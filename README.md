## Overview
An immersive catalog for Minecraft: Bedrock Edition featuring direct download links and other useful integrated features.

## Feature list
### Hub
Included in the `index.html` file as a main header, includes info on downloading specs and finding content.
### Catalog
An immersive catalog with filter and search functions, powered by JavaScript and CSS functions. Popups provide info with Marketplace and direct download links. Additional info is provided via [chunk.gg](https://www.chunk.gg) and the [Minecraft Wiki](https://www.mc.wiki).
